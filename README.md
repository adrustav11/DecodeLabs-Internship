# DecodeLabs-Internship

## Overview
This repository contains Python projects completed during the DecodeLabs Internship.

## Projects

### 1. The Password Strength Checker
**File:** PSC.py
**Description:**
The Password Strength Checker is a simple Python project that helps users determine how secure their passwords are. It checks the password's length and looks for uppercase letters, lowercase letters, numbers, and special characters. Based on these factors, it classifies the password as Weak, Medium, or Strong. This project introduces basic cybersecurity concepts and highlights the importance of creating strong passwords to improve online security.

Basic Cybersecurity Concepts (Password Validation & Strength Analysis)

### 2. Basic Encryption & Decryption Using Caesar Cipher
**File:** encryption_decryption.py
**Description:**
This project implements a basic encryption and decryption system using the Caesar Cipher technique. The program takes a message from the user and encrypts it by shifting each alphabetic character by a specified number of positions. The encrypted message can then be decrypted using the same shift value to recover the original text. The project demonstrates fundamental cybersecurity concepts such as data confidentiality, cryptographic logic, and secure information handling.
## Technologies Used
Python 3
Caesar Cipher Algorithm
ASCII Character Encoding
Built-in Python Functions
ord()
chr()
% (Modulo Operator)

### 3. Phishing Threat Analyzer Using Python
**File:**  Phishing_Awareness_Analysis.py
**Description:**
The Phishing Threat Analyzer is a Python-based cybersecurity application designed to identify potential phishing and scam messages. The system analyzes user-provided text for suspicious keywords, malicious URLs, shortened links, social engineering tactics, sensitive information requests, and dangerous file attachments. Based on the detected threats, it calculates a risk score and classifies the message as Low Risk, Medium Risk, or High Risk. The application also generates security recommendations and saves a detailed threat analysis report for future reference.
